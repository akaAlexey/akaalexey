Данные и конфиденциальность.

Как работают портфолио, публичный API и переход к AGL ID.

Публичные страницы

Портфолио размещено на GitHub Pages. Изображения и шрифты загружаются с сайта; опубликованные тексты и изображения из медиатеки могут загружаться с API AGL на api.alexgamelab.ru. На этом сайте нет регистрации и контактной формы. Хостинг и API обрабатывают технические данные запросов для доставки страниц.

Настройки в браузере

Выбранная тема и последняя загруженная публичная редакция страниц сохраняются локально. Это можно удалить вместе с данными сайта в браузере. Аналитические и рекламные счётчики в код сайта не добавлены.

AGL ID

При переходе к AGL ID используется отдельная система аккаунтов. Она хранит ник, идентификатор аккаунта и, если указана, почту. Данные профиля, роли, игровые сохранения и обращения привязаны к аккаунту. Пароль обрабатывается Keycloak и не хранится в открытом виде. Подробнее — на странице данных AGL.

Внешние ссылки

Канал AGL, GitHub и другие внешние сервисы работают по своим правилам. Telegram-бот для обращений пока не подключён; ссылка будет добавлена после запуска.
