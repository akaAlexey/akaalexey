# Алексей · akaalexey

Готовый статический сайт: HTML, CSS и небольшой JavaScript. Серверное приложение и установка npm-пакетов не нужны.

## Содержимое
- `dist/` — готовые страницы, оптимизированные изображения и локальные шрифты.
- `build.py` — генератор страниц на стандартной библиотеке Python.
- `site_config.json` — тип сайта, адреса связанных сайтов и режим индексации.
- `tools/check_site.py` — проверка ссылок, ресурсов, заголовков и JSON-LD.
- `docs/ART_DIRECTION.md` — происхождение изображений и промпты.

## Изменения
Редактируйте тексты в `build.py` и стили в `dist/assets/site.css`.
Запустите `python3 build.py`, затем `python3 tools/check_site.py` и `node --check dist/assets/site.js`.
Проверьте мобильную версию, клавиатуру, контакты и обе темы.

## Публикация
Текущая версия использует временные адреса для просмотра. Индексация выключена.
При переносе на будущий VPS:
1. Укажите https://alexgamelab.ru и https://akaalexey.ru в `origins`, включите `production` после готовности публичного размещения.
2. Обновите сведения о фактическом хостинге и обработке обращений на странице конфиденциальности.
3. Выполните генерацию и проверку; настройте сервер для раздачи `dist/`, HTTPS и ответа 404 через `404.html`.
4. Проверьте DNS, сертификаты, canonical, sitemap и ссылки между двумя сайтами.

Боты, платежи, формы, аналитика и покупка VPS в эту версию не входят. Контакт — https://t.me/akaAlexey.
Политика приложения «Рублемёт» не подменяется страницей конфиденциальности сайта.
