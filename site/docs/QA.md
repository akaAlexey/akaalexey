# Проверка первой версии

Дата: 5 ноября 2026 года.

- Созданы и проверены 8 страниц: главная, страница проекта, конфиденциальность и 404 для каждого сайта.
- Проверка внутренних ссылок, ресурсов, якорей, заголовков и JSON-LD: AGL — 104 ссылки/ресурса; личный сайт — 92. Ошибок не найдено.
- JavaScript проходит node --check.
- В Chrome проверены настольная версия и размеры 320, 390, 768, 1440 px внутри тестового iframe. Переполнение на 320 px исправлено; после исправления горизонтальная прокрутка отсутствует.
- Проверены переключение темы и сохранение выбора на другой странице личного сайта, мобильное меню и Escape, копирование Telegram-ника, переход к странице конфиденциальности.
- На AGL проверены страница игры, раскрытие ответа в FAQ, открытие галереи и закрытие по Escape.
- Основное содержание и навигация личного сайта проверены при запрете JavaScript в тестовом iframe.
- В коде предусмотрены prefers-reduced-motion, видимый фокус, skip-link, семантические заголовки и подписи управления. Полный независимый аудит WCAG не проводился.
- Главные страницы не показали неуспешно загруженных изображений. Проверены и все локальные пути ресурсов.

Пределы проверки: Firefox, Safari, реальные мобильные устройства и полевые Core Web Vitals в этой среде не проверялись. Технический размер изображений и отсутствие сторонних шрифтов/аналитики проверены; отчёт Lighthouse не подменяется этими проверками.

Временные версии закрыты от поисковой индексации. Перед публичным размещением на доменах нужно проверить фактический хостинг и обновить связанные сведения на странице конфиденциальности. Страница сайта не является политикой приложения «Рублемёт».
